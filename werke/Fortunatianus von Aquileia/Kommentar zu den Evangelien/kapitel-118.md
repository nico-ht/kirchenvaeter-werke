# Kommentar zu den Evangelien – Kapitel 118: Die zwei Menschen auf dem Feld bedeuten: Das christliche Volk wird aufgenommen, das jüdische zurückgelassen

Autor: Fortunatianus von Aquileia

Deutsche Übersetzung: [Die ersten Christen](https://erste-christen.de/werke/fortunatianus/kommentar-zu-den-evangelien#kapitel-9b57443d-2716-43f7-daaf-08df3837a997).

„Dann werden zwei Menschen auf einem Feld sein\.[^bible-52443841-170d-479d-ae50-6b060f09110c]“ Er nennt die Welt ein Feld\.[^bible-ef285d11-dce6-4360-aad2-65251afc65fd] Auf diesem Feld gibt es also, wie er zeigt, zwei Völker: Das eine wird aufgenommen, das andere zurückgelassen\.[^bible-52443841-170d-479d-ae50-6b060f09110c] So ist das christliche Volk durch seine Lebensführung im Himmel, auch wenn es auf dem Feld \(also in der Welt\) zu sein scheint, wie der Apostel sagt: „Unsere Lebensführung aber ist oben im Himmel\.[^bible-d59c2374-fdc6-424c-ad62-b9deca79c390]“ Dasselbe zeigt sich auch an Jakobs Leiter, auf der die einen hinaufstiegen und die anderen hinabstiegen[^bible-0dafc095-8219-4b17-b2eb-2a5cabeb6b94]\. So steigt das jüdische Volk hinab: Es bleibt auf dem Feld, oder vielmehr: Es wird dort tatsächlich zurückgelassen\. Das christliche Volk steigt hinauf, indem es aufgenommen wird und Christus entgegengeht[^bible-fd5b0d46-6b5d-40db-8461-f5843ba14cb9]\.
