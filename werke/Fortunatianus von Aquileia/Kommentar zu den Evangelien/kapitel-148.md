# Kommentar zu den Evangelien – Kapitel 148: Das Sinken der beiden Boote bedeutet die Taufe in der Kirche, in der Christus stets gegenwärtig ist

Autor: Fortunatianus von Aquileia

**Nicht kommerziell · Quelle nennen · Bearbeitungen unter gleicher Lizenz**

Deutsche Übersetzung: [Die ersten Christen](https://erste-christen.de/werke/fortunatianus/kommentar-zu-den-evangelien#kapitel-5690ed23-9279-4066-dacd-08df3837a997).

„Und sie füllten beide Boote so voll, dass sie sanken\.[^bible-1b7b7b33-e73f-40f1-a278-12a05c628156]“ Dass die beiden Boote mit einer Menge Fische gefüllt wurden, so voll, dass sie sanken[^bible-1b7b7b33-e73f-40f1-a278-12a05c628156], zeigt den Grund für die beiden Berufungen\. „So voll, dass sie sanken[^bible-1b7b7b33-e73f-40f1-a278-12a05c628156]“: Denn sinken heißt nichts anderes als getauft werden\. Es ist nämlich Brauch und Lehre der Kirche, dass die Kinder Gottes, die zu ihr kommen, durch die Wiedergeburt aus dem Wasser geistlich erneuert werden\. „So voll, dass sie sanken[^bible-1b7b7b33-e73f-40f1-a278-12a05c628156]“ bedeutet also, dass sie getauft wurden\. Weil Jesus im Boot war[^bible-ddacff2f-eab8-485b-a61b-1af9e85808b6], müssen wir darin erkennen, dass Jesus, unser Erlöser, immer im Schiff ist \(damit ist die Kirche gemeint\)\. So werden in seinem Namen alle getauft, die zur Kirche kommen\.
