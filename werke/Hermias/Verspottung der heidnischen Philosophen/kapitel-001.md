# Verspottung der heidnischen Philosophen – Kapitel 1: Die widersprüchlichen Lehren der Philosophen über die Seele erweisen weltliche Weisheit als Torheit

Autor: Hermias

Ihr Lieben, als Paulus, der selige Apostel, an die Korinther schrieb, die im lakonischen Griechenland wohnen, erklärte er: „Die Weisheit [^bible-6d28ea16-26fe-4351-9591-670de4baa48d]dieser Welt [^bible-6d28ea16-26fe-4351-9591-670de4baa48d]ist [^bible-6d28ea16-26fe-4351-9591-670de4baa48d]Dummheit [^bible-6d28ea16-26fe-4351-9591-670de4baa48d]bei [^bible-6d28ea16-26fe-4351-9591-670de4baa48d]Gott[^bible-6d28ea16-26fe-4351-9591-670de4baa48d]\.“ Das sagte er nicht ohne Grund\. Denn mir scheint, dass sie ihren Ursprung im Abfall der Engel hat\. Deshalb legen die Philosophen ihre Lehren dar, ohne in ihren Aussagen miteinander im Einklang zu stehen oder übereinzustimmen\. Denn einige von ihnen sagen, die Seele sei Feuer, etwa Demokrit; die Stoiker halten sie für Luft; andere für Geist; andere für Bewegung, so Heraklit\. Andere halten sie für Ausdünstung; andere für eine Kraft, die von den Sternen ausströmt; andere für eine bewegende Zahl, so Pythagoras; andere für zeugungskräftiges Wasser, so Hippon\. Andere halten sie für ein Element aus Elementen; andere für Harmonie, so Deinarchos; andere für Blut, so Kritias; andere für Hauch; andere für die Einheit, so Pythagoras; und die Alten lehren Gegensätzliches\. Wie viele Erörterungen gibt es darüber? Wie viele Beweisversuche? Und wie viele davon stammen von Sophisten, die eher streiten als die Wahrheit finden?
