# Fragen zur Genesis – Kapitel 80: Rebekkas Vertrauen auf Gottes Vorhersage gab ihr die Zuversicht, Jakob den väterlichen Segen zu sichern

Woher nahm Rebekka die Zuversicht, dass Jakob den Segen erhalten würde, eine so große Zuversicht, dass sie sagte: „Dein Fluch komme auf mich, mein Kind; höre nur auf meine Stimme[^bible-5fcdf64b-410c-4a9e-90c5-b209ab812a7a]“? Sie hatte schon zuvor vom Gott des Alls erfahren: „Der Ältere wird dem Jüngeren dienen\.[^bible-2ae296fb-ea47-43b6-b682-af969663d677]“ Im Vertrauen auf diese Vorhersage setzte sie alles daran, dass Jakob den Segen seines Vaters empfing\.
