# Fragen zu Exodus – Kapitel 46: Der lebenslange Sklavendienst zeigt, dass „Äon“ nicht immer eine unbegrenzte Zeit bezeichnet

Warum wird hinzugefügt: „Und er wird ihm auf ewig als Sklave dienen[^bible-11b6bcb4-1a08-4a84-8c53-e050ce2669c6]“, obwohl die Grenzen des menschlichen Lebens bekannt sind? Daran zeigt sich, dass das Wort Äon nicht überall eine unbegrenzte, sondern bisweilen auch eine begrenzte Zeit bezeichnet\. So sagt auch der selige David: „Unser Äon liegt im Licht deines Angesichts\.[^bible-7991b82f-22ef-4c86-a58c-afb3fd9a7f62]“ Damit bezeichnete er das menschliche Leben\.
