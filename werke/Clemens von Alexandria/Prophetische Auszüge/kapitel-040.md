# Prophetische Auszüge – Kapitel 40: Gottes Gericht ist gut: Es scheidet Gläubige von Ungläubigen, erzieht und soll vor schwererem Gericht bewahren

Autor: Clemens von Alexandria

Wie sie durch das Ausströmen des Guten gut werden, so werden sie auch durch das Ausströmen des Bösen böse\. Gut ist das Gericht Gottes: die Scheidung der Gläubigen von den Ungläubigen, das vorausgehende Gericht, das vor einem schwereren Gericht bewahren soll, und das Gericht, das Erziehung ist\.
