# Prophetische Auszüge – Kapitel 48: Abgetriebene Kinder erhalten teils durch Erkenntnis die bessere Wohnstätte, teils nur Rettung aus Erbarmen

Autor: Clemens von Alexandria

So sagt etwa Petrus in der Apokalypse: „Die abgetriebenen Kinder, denen das bessere Los zuteilwerden wird, werden einem Engel übergeben, der für sie sorgt, damit sie Anteil an der Erkenntnis erhalten und so die bessere Wohnstätte erlangen, nachdem sie durchgemacht haben, was sie auch durchgemacht hätten, wenn sie in einem Körper zur Welt gekommen wären\.“ Die anderen aber werden nur die Rettung erlangen, weil ihnen Erbarmen erwiesen wird, da sie Unrecht erlitten haben\. Sie werden von Strafe verschont bleiben und dies als Ehrengabe erhalten\.
