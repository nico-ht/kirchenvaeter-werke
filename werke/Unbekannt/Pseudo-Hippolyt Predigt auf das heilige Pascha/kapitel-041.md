# Pseudo\-Hippolyt: Predigt auf das heilige Pascha – Kapitel 41: Das eine Haus bezeichnet die eine Kirche, in der allein der heilige Leib Christi gegessen werden darf

„In einem einzigen Haus soll es gegessen werden, und ihr sollt nichts von dem Fleisch nach draußen bringen[^bible-b64176f6-2902-4d86-996f-95e3312c2622]\.“ Denn es gibt nur eine Versammlung und nur ein Haus, nämlich die eine Kirche, in der der heilige Leib Christi gegessen wird\. Darum wird das Fleisch nicht aus dem einen Haus[^bible-b64176f6-2902-4d86-996f-95e3312c2622], der Kirche, hinausgebracht[^bible-b64176f6-2902-4d86-996f-95e3312c2622]\. Wer aber anderswo davon isst, wird als Gottloser und Dieb bestraft werden\.
