# Pseudo\-Hippolyt: Predigt auf das heilige Pascha – Kapitel 59: Wie eine Frau zuerst die Sünde in die Welt brachte, verkündet eine Frau zuerst das Leben der Auferstehung

Nach seiner Auferstehung sehen ihn zuerst die Frauen[^bible-3df52ad4-68d4-4cb3-8336-e0a6c275857f]\. Denn wie eine Frau als Erste die Sünde in die Welt brachte[^bible-2ed1c75b-b3d8-43f4-b9fe-43033102da02], so verkündet auch eine Frau der Welt als Erste das Leben\. Darum hören sie auch die heilige Stimme: „Frauen, freut euch\![^bible-3df52ad4-68d4-4cb3-8336-e0a6c275857f]“, damit der erste Schmerz von der Freude über die Auferstehung verschlungen wird\.
